# 📘 Input / Output in Java

---

# 🔹 1. Introduction

Input/Output (I/O) is used to:

```text id="io1"
Take input from user  
Display output to console  
```

---

# 🔹 2. Basic Output (Print Statements)

---

## 🔸 print()

```java id="io2"
System.out.print("Hello");
System.out.print("World");
```

👉 Output:

```text id="io3"
HelloWorld
```

---

## 🔸 println()

```java id="io4"
System.out.println("Hello");
System.out.println("World");
```

👉 Output:

```text id="io5"
Hello
World
```

---

## 🔸 printf() (Formatted Output)

```java id="io6"
System.out.printf("Value: %d", 10);
```

👉 Format Specifiers:

```text id="io7"
%d → integer  
%f → float  
%s → string  
%c → char  
```

# 🔹 3. Taking Input using Scanner

---

## 🔸 Import Scanner

```java id="io8"
import java.util.*;
```

---

## 🔸 Create Scanner Object

```java id="io9"
Scanner sc = new Scanner(System.in);
```

---

## 🔸 Input Methods

```java id="io10"
int n = sc.nextInt();
long l = sc.nextLong();
double d = sc.nextDouble();
String s = sc.next();
String line = sc.nextLine();
char c = sc.next().charAt(0);
```

---

## 🔸 Example Program

```java id="io11"
import java.util.*;

class Main {
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        String name = sc.next();

        System.out.println(n);
        System.out.println(name);
    }
}
```

---

# 🔹 4. Important Scanner Notes

```text id="io12"
next() → reads word  
nextLine() → reads full line  
```

---

## 🔸 Common Issue

```java id="io13"
int n = sc.nextInt();
String s = sc.nextLine(); // issue
```

👉 Fix:

```java id="io14"
int n = sc.nextInt();
sc.nextLine(); // consume leftover newline
String s = sc.nextLine();
```

# 🔹 5. Fast Input (BufferedReader)

---

## 🔸 Why Use?

```text id="io15"
Scanner is slow for large input  
BufferedReader is faster  
```

---

## 🔸 Code

```java id="io16"
import java.io.*;

BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

int n = Integer.parseInt(br.readLine());
String[] input = br.readLine().split(" ");
```

---

# 🔹 6. Fast Output (BufferedWriter)

```java id="io17"
BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

bw.write("Hello\n");
bw.flush();
```

---

# 🔹 7. StringTokenizer (Faster Parsing)

```java id="io18"
import java.util.*;

StringTokenizer st = new StringTokenizer(br.readLine());

int a = Integer.parseInt(st.nextToken());
int b = Integer.parseInt(st.nextToken());
```

# 🔹 8. Input Patterns

---

## 🔸 Array Input

```java id="io19"
int n = sc.nextInt();
int[] arr = new int[n];

for(int i = 0; i < n; i++){
    arr[i] = sc.nextInt();
}
```

---

## 🔸 2D Array Input

```java id="io20"
int[][] mat = new int[n][m];

for(int i = 0; i < n; i++){
    for(int j = 0; j < m; j++){
        mat[i][j] = sc.nextInt();
    }
}
```

---

## 🔸 Multiple Test Cases

```java id="io21"
int t = sc.nextInt();

while(t-- > 0){
    int n = sc.nextInt();
}
```
